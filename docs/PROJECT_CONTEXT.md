# Project Context — Quinzena

## Autonomia
O ChatGPT está autorizado pelo proprietário do projeto a tomar decisões de produto, UX/UI, design, código, arquitetura, testes, segurança, priorização e estratégia sem solicitar aprovação para cada decisão, preservando integridade dos dados e o objetivo comercial.

## Deadline
Lançamento comercial até 10/09/2026.

## Produto
Quinzena é uma PWA mobile-first para pessoas que recebem renda em duas datas e precisam entender qual pagamento banca cada conta e quanto sobra em cada ciclo.

## Prioridades
1. Integridade financeira e ausência de cálculos enganosos.
2. Experiência excelente no celular.
3. Simplicidade de uso.
4. Privacidade local-first.
5. Produto vendável dentro do prazo.

## Segurança do repositório público
O repositório é público. Nunca incluir dados reais do proprietário, credenciais, tokens, chaves, segredos, backups financeiros reais, dados de clientes ou meios de pagamento. Exemplos e fixtures devem ser fictícios.

## Produção
A versão hospedada é publicada via GitHub Pages/GitHub Actions em:
https://jhony4lves.github.io/Quinzena/

## Escopo fora do lançamento inicial
Open Finance, login, IA, sincronização cloud, integração bancária, investimentos, multiusuário e recursos que coloquem o deadline em risco.
