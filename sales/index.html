PERGUNTAS RÁPIDAS

FAQ

Preciso receber exatamente nos dias 1 e 15?

Não. As duas datas e os percentuais são configuráveis.

Meus dados vão para a nuvem?

Na versão inicial, não. O produto é local-first e oferece exportação de backup.

É assinatura?

A oferta inicial foi desenhada como pagamento único. Serviços de nuvem futuros, se existirem, serão produtos separados.

Serve para quem recebe uma vez no mês?

Até pode ser adaptado, mas esse não é o foco. O Quinzena foi criado para resolver o fluxo entre duas entradas recorrentes.
